Application Overview

BuildTakeoff Pro is a professional construction estimation and digital takeoff platform. Phase 1 delivers core drawing management, line measurement, member schedule tracking, and report export — designed for structural steel estimation workflows.

Stack

React 19 + Vite (Frontend)
ASP.NET Core 9 (API)
SQL Server (Database)

Ports

Frontend: localhost:5173
Backend API: localhost:5000
Swagger: localhost:5000/swagger

Key Features

PDF Drawing Viewer
Line Measurement Tool
Member Schedule + Export

1
Starting the Application

Open two separate terminals and run the following commands:

# Terminal 1 — Backend API cd "e:\Construction Project\backend\ConstructionEstimation.API" dotnet run # Wait for: "Now listening on: http://localhost:5000"
# Terminal 2 — Frontend cd "e:\Construction Project\frontend" npm run dev # Wait for: "Local: http://localhost:5173/"
ℹ️

Open your browser and navigate to http://localhost:5173. Both servers must be running simultaneously. If the backend is not running, the frontend will show a blank/error state.

6
Scale Calibration (Critical — do this before measuring)
⚠️

Without calibration, all measurements are shown in pixels rather than real-world units (mm, m, ft). Always calibrate before taking measurements on a new drawing.

  1. 1
    Click the Calibrate (orange) tool in the toolbar — a hint appears: "Draw a line of known length"
  2. 2
    On the drawing, find a known dimension — e.g. a column grid spacing of 6000 mm
  3. 3
    Click the start point → click the end point of that known dimension
  4. 4
    In the Right Panel, the calibration form appears: enter 6000 and select mm
  5. 5
    Click Apply

After calibration:

  • Toast: "Scale calibrated successfully"
  • Drawing card in sidebar shows a green dot ● Calibrated
  • Breadcrumb bar shows a green CALIBRATED badge
  • Right panel shows: ✓ Calibrated · mm
  • All subsequent measurements show real-world values

Troubleshooting Quick Reference
SymptomLikely CauseFix
Login fails immediately Backend not running Run dotnet run in the API project. Check Terminal 1 shows "listening on port 5000"
Blank page / white screen JavaScript crash in the app Press F12 → Console tab → read the red error. Usually backend is offline or a store state issue. Refresh the page
"Drawing file not found" on the viewer Backend offline or file missing from disk Restart backend. If persists, the file was deleted from the Uploads folder — re-upload the drawing
"Authentication error" on the viewer JWT token expired Log out and log back in to get a fresh token
Measurements not saving 401 Unauthorized (expired token) Open F12 → Network tab, look for red 401 responses. Log out and log back in
Member total weight is zero Length entered in wrong unit Member Schedule expects Length in metres. E.g. enter 4.5 not 4500
Excel/PDF buttons missing No measurements saved yet Save at least 1 measurement — buttons appear automatically in the breadcrumb bar
PDF shows blank / loading spinner forever PDF.js worker not loaded Stop the frontend dev server and run npm run dev again — it copies the PDF worker on startup
Calibration gives wrong measurements Incorrect reference length or unit Click "Re-calibrate Scale" in the right panel. Draw the reference line more carefully. Ensure the unit matches the value entered
"Failed to load drawings" toast Network error to API Confirm backend is running on port 5000. Check Vite proxy is active (dev server must be running via npm run dev)
Data doesn't appear after refresh EF migration not applied The backend auto-runs migrations on startup. Stop and restart the backend to trigger a re-migration
