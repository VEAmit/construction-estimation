Application Overview

BuildTakeoff Pro is a digital construction takeoff and estimation system designed for structural engineers and estimators. It provides a simplified Bluebeam-style workflow for measuring structural drawings, calculating quantities, and generating professional estimation reports.

What the System Does

  • Open and view structural PDF drawings in-browser
  • Calibrate drawing scale from any known dimension
  • Draw measurement lines directly on the drawing
  • Auto-calculate real-world lengths using the calibrated scale
  • Auto-save all measurements to a central database
  • Build a structural steel member schedule
  • Auto-calculate member weights (UnitWeight × Length × Qty)
  • Export professional Excel and PDF reports

Technology Stack

DatabaseSQL Server

Core Workflow (Summary)

1. Login → Select Project → Open Drawing
2. Calibrate Scale → draw a line on a known dimension → enter real length
3. Measure → draw lines on structural elements → auto-saves with real-world length
4. Member Schedule → add steel members → link to measurements → weight auto-calculates
5. Export → Excel or PDF report with all data

Set Drawing Scale Required Before Measuring

Important — Must Do First
Scale calibration must be completed before taking any measurements. If you try to use the Measure tool before calibrating, the system will automatically redirect you back to Calibrate with a guide message. Measurements drawn before calibration will have no real-world length value.

Method A — Calibrate from a Known Dimension Most Accurate

Use this method whenever you have a dimension on the drawing you know the real-world size of (e.g. a grid line marked 5000mm, a door opening, column spacing).

StepActionExpected Result
19Click Calibrate button in toolbar or press CToolbar shows amber hint: "Step 1 of 2 — Draw a line over a dimension you know…"
20Zoom into the drawing to find a dimension you know (e.g. a grid marked "5000")Drawing zooms. You can now see the dimension clearly
21Click the start point of that known dimension on the drawingAmber dot placed at start point
22Click the end point of that same dimensionAmber line drawn. Calibration dialog pops up automatically
23In the dialog, enter the real-world length (e.g. 5 for 5 metres)Scale preview shows: "X.XXXX mm / drawing unit"
24Select the correct unit from the dropdown (mm, cm, m, ft, in)Unit selection updates the preview
25Click Apply Scale• Amber calibration line disappears from drawing
• Right panel shows green ✓ Calibrated · m
• Breadcrumb shows green CALIBRATED badge
• Tool auto-switches to Measure mode

Method B — Quick Scale Preset Approximate

Use when you know the drawing scale (e.g. 1:100) but don't have a specific dimension to measure. Works best with standard A-size PDFs exported at full print scale.

StepActionExpected Result
26In the right panel, locate "Quick Scale (approx.)" sectionVisible only when drawing is not yet calibrated
27Select a scale from dropdown: 1:10, 1:20, 1:50, 1:100, 1:200, 1:500, 1:1000Scale value selected
28Select the display unit (m, mm, cm, ft, in)Unit selected
29Click Apply 1:100 Scale• Right panel shows green Calibrated badge
• Tool auto-switches to Measure mode
How to Verify the Scale is Correct
After calibration, the right panel shows: "1 unit = 0.0706 m" (for 1:200 scale). To verify, use the Measure tool to draw over the same calibration dimension — the saved length should match what you know.

Re-calibrate (if needed)

Click Re-calibrate Scale in the right panel at any time. The new scale applies to all future measurements. Previously saved measurements retain their original values.

Important — Calibrate Mode vs. Measure Mode
  • Lines drawn in Calibrate mode (amber lines) are for setting scale only — they are NOT saved as measurements
  • Lines drawn in Measure mode (blue lines) are saved automatically to the database
  • If you see old amber/red lines on the drawing from calibration practice, click the Clear button to remove them
  • The Measure tool shows a blue highlight when active. Calibrate shows an amber highlight

Weight Calculation Formula

Total Weight (kg) = Unit Weight (kg/m) × Length (m) × Quantity

Example: A 310UB46 beam, 3.5 m long, with 4 pieces:
Total Weight = 46.2 × 3.5 × 4 = 646.8 kg

Troubleshooting Guide

ProblemLikely CauseSolution
Measure tool switches back to Calibrate automatically Drawing not yet calibrated Complete calibration first (Section 05). The guard prevents uncalibrated measurements.
Lines drawn on drawing don't appear in the Measurements table Lines were drawn in Calibrate mode, not Measure mode Check toolbar: Measure must be active (blue). Click Clear to remove old calibration lines, then click Measure and draw new lines.
Old red/amber lines still visible on drawing Calibration lines not cleared (delete annotation may not have fired) Click the Clear button in the toolbar. This removes all drawn lines from the viewer. Saved measurements in the table are not affected.
Length shows "—" in the Measurements table Measurement was drawn before calibration was set Delete that row (trash icon) and re-draw the line in Measure mode after calibrating.
Syncfusion labels on drawing show "2.47 in" (wrong unit) Syncfusion's internal label display uses its own unit system Ignore the label shown on the drawing line. The correct length is the value shown in the Measurements table, which uses your calibrated scale.
Scale looks wrong / lengths seem too large or too small Calibration was done on a very short line, or wrong value entered Click Re-calibrate Scale in the right panel. Use a longer, well-defined dimension for better accuracy. Method A (draw on drawing) is more accurate than Method B (preset).
Member Schedule Total Weight is 0 or blank Unit Weight or Length is 0 Check that Unit Weight is set (select a steel section size — it auto-fills) and Length is greater than 0.
Length not auto-filling in Member Schedule Linked Measurement has no calibrated length (length is null) The linked measurement must have a valid length. Draw measurements after calibrating. Check the measurement's Length column is not "—".
Export buttons not visible No measurements saved yet Draw at least one measurement line first. Export buttons appear once the table has data.
PDF drawing takes a long time to load Large PDF file size This is normal for large construction drawings. Syncfusion renders PDF in the browser using WebAssembly. Wait for the spinner to complete. Subsequent views are faster.
Page shows "Could not load drawing" Backend not running or file not found Ensure the backend is running on port 5000. If using a re-uploaded drawing, delete the old entry and upload again.

Scale Formula Reference

ScaleRatio (mm per PDF point) = RealLength_mm / PixelLength_pts
PixelLength_pts = Euclidean distance between clicked points in PDF coordinate space
RealWorldLength = PixelLength × ScaleRatio → converted to display unit
TotalWeight (kg) = UnitWeight (kg/m) × toMeters(Length, Unit) × Quantity

Quick Scale Preset Formula

ScaleRatio = N × (25.4 / 72) mm/pt
where N = scale denominator (e.g. 100 for 1:100)
Assumes: standard PDF at 72 DPI print resolution

Immediate Action Required for Testing
The TakeoffItems table is empty because the lines currently visible on the drawing were drawn in Calibrate mode, not Measure mode. To populate measurements:
  1. Click the Clear button in the toolbar to remove old calibration lines
  2. Click Measure button (or press L) — the drawing is already calibrated
  3. Draw 3–4 measurement lines on structural elements
  4. Each line will auto-save and appear in the Measurements table immediately
