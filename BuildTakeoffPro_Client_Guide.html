Application Overview

BuildTakeoff Pro is a full-stack web application for construction quantity estimation and digital takeoff. It is built for structural engineers, estimators, and project managers who work with PDF drawings. The platform provides a professional Bluebeam-style workflow — entirely in the browser, with no additional software required.

Components
📄
PDF Drawing Viewer
Upload & view structural PDFs up to 100 MB. Multi-page support. Client-side rendering via Syncfusion WASM.
📏
Digital Takeoff
Draw lines, polygons, rectangles, and count markers directly on the PDF. Measurements auto-save with real-world unit conversion.
⚖️
Scale Calibration
Calibrate once per drawing. All measurements automatically convert to mm, cm, m, feet, or inches.
🏗️
Member Schedule
Full steel member schedule: mark, section size, unit weight (kg/m), length, quantity, total weight (kg).
🤖
OCR Extraction
Auto-scan PDF for steel member notations using PdfPig text extraction + Tesseract OCR fallback. Preview before saving.
📊
Excel & PDF Export
Export full reports to XLSX (3 sheets: Summary, Measurements, Member Schedule) or a professional landscape PDF.

Core Workflow Summary

1. Login → Select / Create Project → Open Drawing
Dashboard shows all projects. Click a project to enter the workspace.

2. Upload PDF Drawing → Calibrate Scale
Draw a reference line on a known dimension → Enter real length → Scale set (e.g. 1 pixel = 20 mm)

3. Take Measurements → Line / Area / Rectangle / Count tools
Each drawing auto-saves with real-world length. Auto-assigned marks: M1, A1, C1…

4. Build Member Schedule → Manual or Auto-Extracted from PDF
OCR scans PDF for "310 UB 40.4", "200 PFC", etc. Unit weight auto-fills from AS 4100 tables.

5. Export → Excel (XLSX) or PDF Report
3-sheet Excel workbook or landscape PDF with tables, totals, project info, and date.

Set Drawing Scale (Calibration) Required Before Measuring

Must Do First
Scale calibration must be completed before taking any measurements. If you attempt to use the Measure tool without calibrating, the system will prompt you to calibrate first. Measurements taken before calibration will have no real-world length value.

Method A — Draw on a Known Dimension Most Accurate

Use when you have a dimension shown on the drawing that you know the real-world size of (e.g. a grid line labelled "5000mm", a column spacing, a door opening).

StepActionExpected Result
22Click Calibrate tool in toolbarToolbar shows amber hint: "Draw a line over a dimension you know…"
23Zoom into a known dimension on the drawingDimension clearly visible
24Click the start point of that dimensionAmber dot placed
25Click the end point of that dimensionAmber line drawn. Calibration dialog opens automatically.
26Enter the real-world length (e.g. 5) and select unit (e.g. Meter)Scale preview shows: "1 pixel = X.XX mm"
27Click Apply Scale• Amber line disappears from drawing
• Right panel shows ✓ Calibrated
• Tool auto-switches to Measure mode

Method B — Quick Scale Preset Approximate

Use when you know the drawing scale (e.g. 1:100) but don't have a specific dimension to draw over.

StepActionExpected Result
28In the right panel, find "Quick Scale" sectionVisible when drawing is not yet calibrated
29Select a scale: 1:10, 1:20, 1:50, 1:100, 1:200, 1:500, 1:1000Scale selected
30Select the display unit (m, mm, cm, ft, in)Unit selected
31Click Apply Scale• Right panel shows ✓ Calibrated
• Tool auto-switches to Measure mode

Scale Formula Reference

Scale Ratio (mm/pixel) = RealLength_mm ÷ PixelLength
RealWorldLength = PixelLength × ScaleRatio → converted to selected display unit

Example: Reference line = 100 pixels · Real length = 2000 mm
Scale Ratio = 2000 ÷ 100 = 20 mm/pixel
50-pixel line × 20 = 1000 mm = 1.0 m
Persistence
Scale calibration is stored in the database per drawing (ScaleRatio + CalibrationUnit). Reloading the page restores the calibrated state. The right panel shows ✓ Calibrated · m when active.

Auto-Extraction — Steel Members from PDF AI / OCR Feature

The Extraction feature automatically scans the uploaded PDF drawing for structural steel section notations and builds a suggested Member Schedule. The user reviews, edits, and confirms before anything is saved.

Extraction Modes

ModeMethodSpeed
Text PDFUglyToad PdfPig — reads native text from PDFFast
Scanned PDFPDFtoImage → Tesseract OCR engineSlower

Recognised Section Types

PatternExample
Universal Beam/Column310 UB 40.4, 250 UC 89.5
Parallel Flange Channel200 PFC, 150 PFC
Hollow Section (RHS/SHS/CHS)150×150×6 RHS, 76.1×3.2 CHS
Member MarksB1, C2, G3, P4, R5

Extraction Workflow

StepActionExpected Result
58Open a drawing → click Schedule Extract button (right panel)Loading spinner. System scans the PDF — text mode first, OCR fallback if needed.
59Extraction Modal opensPreview list of found members: Mark, Section Size, Type, Unit Weight, Length, Quantity, Confidence %
60Review the list — edit quantities, marks, or lengths as neededFields are editable in the modal
61Click the × on any entry to remove invalid/irrelevant itemsItem removed from preview (not yet in database)
62Click Confirm to save the reviewed listAll items saved to Member Schedule (bulk insert). Toast confirms count.
63Switch to Members tabAll confirmed members visible. Summary: total members, total qty, total weight (kg).
Built-in Weight Lookup
The extraction engine includes a built-in lookup table for Australian standard steel sections (AS 4100). When a section like "310 UB 40.4" is found, the unit weight (40.4 kg/m) is automatically assigned. For unrecognised sections, the weight field is left blank for manual entry.
Preview Before Save
The extraction result is a preview only — nothing is saved until you click Confirm. You can edit any field or remove items before confirming. This lets you filter out irrelevant text matches before they enter the schedule.

Troubleshooting Guide

ProblemLikely CauseSolution
Measure tool prompts calibration Drawing not yet calibrated Complete calibration first (Section 06). The system guards against uncalibrated measurements.
Lines drawn but nothing appears in Measurements table Lines drawn in Calibrate mode, not Measure mode Check toolbar — Measure must be active (blue highlight). Click Clear to remove old lines, then re-select Measure and draw again.
Old amber/red lines still visible on drawing Calibration lines not removed Click the Clear button in the toolbar. Saved measurements in the table are unaffected.
Length shows "—" in the table Measurement was taken before calibration Delete that row and re-draw the line after calibrating.
Scale looks wrong / lengths seem too large or small Short calibration line, or wrong value entered Click Re-calibrate in the right panel. Use a longer, well-defined dimension. Method A is more accurate than Method B (preset).
Member Schedule Total Weight is 0 or blank Unit Weight or Length is 0 Select a section size (Unit Weight auto-fills) and ensure Length is greater than 0.
OCR Extraction finds no members PDF is a scanned image with low contrast or unusual fonts The system falls back to Tesseract OCR automatically. For very poor-quality scans, manually add members via + Add Member.
Export buttons not visible No measurements saved yet Draw and save at least one measurement. Export buttons appear once the table has data.
PDF takes a long time to load Large PDF file / first-time WASM load Normal for large construction drawings. Syncfusion renders PDF via WebAssembly in the browser. Subsequent loads are faster (cached).
Page shows "Could not load drawing" Backend not running or file missing Ensure npm run dev is running. If the file is missing from the server, delete the drawing entry and re-upload.
Login fails with valid credentials Backend not started or DB not connected Ensure backend is running on port 5000. Check SQL Server connection. The DB is auto-created on first startup.
